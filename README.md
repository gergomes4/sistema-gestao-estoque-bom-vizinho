# Sistema de Gestão de Estoque – Bom Vizinho

## Sobre o projeto
Este projeto tem como objetivo desenvolver um sistema web simples para auxiliar no controle de estoque de um pequeno mercado.

A solução busca facilitar o cadastro de produtos, o registro de entradas e saídas, o acompanhamento das quantidades disponíveis e a identificação de produtos próximos do vencimento.

## Objetivo
Melhorar a organização do estoque, reduzir erros nos registros e ajudar a evitar desperdícios de mercadorias.

## Tecnologias previstas
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- Pytest

## Funcionalidades previstas
- Cadastro e consulta de produtos.
- Atualização e exclusão de produtos.
- Registro de entradas e saídas.
- Alerta de estoque baixo.
- Alerta de produtos próximos do vencimento.

## Status do projeto
Em fase inicial de desenvolvimento.
